# Prévia 5 — primeira abertura e desinstalação interativa

A tela Monitoramento orienta a iniciar o diagnóstico no Início quando ainda não há sessão.
A lista de retenção em Configurações exibe o rótulo em português e tem nome para tecnologias
assistivas. As opções de retenção e os dados persistidos usam o mesmo contrato.

## Ensaios locais

- **Suíte padrão.** Compilação Release sem erros ou avisos, 92 testes unitários e 58 integrados
  aprovados. O novo teste de regressão cobre a abertura do Monitoramento sem uma sessão.
- **Primeira abertura instalada.** Pacote de laboratório com identidade e armazenamento próprios
  no mesmo Windows do notebook. Registro, destino do atalho e versão conferidos. Interface WPF
  executada com o caminho do SDK retirado do ambiente. Abertura em Início, inventário passivo
  disponível e navegação pelas cinco telas. Monitoramento sem sessão e sem cancelamento,
  Resultados sem exportação disponível e Histórico vazio. O banco e as preferências foram
  gravados na pasta de laboratório.
- **Desinstalador com o GCM aberto.** O processo da interface instalada manteve o marcador de uso.
  O desinstalador recusou a operação e preservou o registro do pacote.
- **Desinstalação interativa com preservação.** Sessão e PDF demonstrativos preparados com o
  motor instalado. A opção **Não** no diálogo de remoção de dados foi confirmada na interface.
  O registro, o atalho e o executável foram removidos. Banco, preferências e PDF mantiveram
  os mesmos hashes.
- **Retenção.** O pacote corrigido exibiu **Revisar após 90 dias** após carregar as preferências
  de ensaio. A caixa de combinação foi identificada como **Retenção do histórico**.
- **Desinstalação interativa com limpeza.** A opção **Sim** removeu banco, preferências e
  temporário gerenciado. O PDF e o arquivo desconhecido mantiveram seus hashes. A interface
  informou que alguns dados foram preservados. Registro, atalho e executável foram removidos.
- **Instalação existente.** A prévia 3 continuou registrada. Os hashes do aplicativo
  e do banco reais conferiram antes e depois.

O teste adicional do motor instalado que preparou os dados demonstrativos também passou.
Foram **151 testes locais aprovados** e a
[validação do GitHub Actions no Windows](https://github.com/Taconi2003/GCM-MONITOR/actions/runs/42374743312)
passou, incluindo a publicação self-contained.

O comando `./scripts/package.ps1 -LabUi` gera o pacote de ensaio. O aplicativo de laboratório
usa a pasta `profile` ao lado da instalação. O pacote distribuível é gerado pelo comando padrão.
Veja [como reproduzir](../../installer/InnoSetup/README.md).

O ensaio usa um diretório de dados inicialmente vazio em um perfil Windows existente.
A primeira abertura em uma máquina recém-instalada e a matriz de versões Windows 10/11
continuam pendentes. Nenhum teste de estresse foi executado.
